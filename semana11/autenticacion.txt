El login es el proceso que permite identificar y autenticar a un usuario antes de acceder a una aplicación. 
Gracias a este mecanismo, cada persona puede ingresar únicamente a las funciones 
que le corresponden según sus permisos.

Algunas rutas deben estar protegidas porque contienen información privada o permiten realizar acciones importantes 
que no deben estar disponibles para cualquier usuario. 

Esto ayuda a mantener la seguridad y evitar accesos no autorizados. 
Además, no se deben exponer públicamente contraseñas, documentos de identidad, direcciones, números de teléfono, claves de API, 
tokens ni otros datos sensibles de la comunidad.
